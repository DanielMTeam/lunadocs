# <Badge text="GET" variant="note" size="medium" /> `/method/marketplace/search`

Метод позволяет выполнить поиск приложений, исходя из текстового запроса.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `query` | `string` | **Да** | Текстовый запрос ^_^ |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/search?query=lorem_impus' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    params = {
        'query': 'lorem_impus',
    }

    response = requests.get('https://api.lunastore.app/method/marketplace/search', params=params)
    print(response.json())
    ```
  </TabItem>
  <TabItem label="Go" icon="seti:go">
    ```go
    resp, err := http.Get("https://api.lunastore.app/method/marketplace/search?query=lorem_impus")
    ```
  </TabItem>
  <TabItem label="C#" icon="seti:c-sharp">
    ```csharp
    using System;
    using System.Net.Http;
    using System.Threading.Tasks;

    class Program
    {
        static async Task Main()
        {
            using var client = new HttpClient();
            var url = "https://api.lunastore.app/method/marketplace/search?query=lorem_impus";
            
            try
            {
                string response = await client.GetStringAsync(url);
                Console.WriteLine(response);
            }
            catch (HttpRequestException e)
            {
                Console.WriteLine($"Error of request: {e.Message}");
            }
        }
    }
    ```
  </TabItem>
  <TabItem label="C++" icon="seti:cpp">
    ```cpp
    #include <iostream>
    #include <string>
    #include <curl/curl.h>

    // callback for write answer in string
    size_t WriteCallback(void* contents, size_t size, size_t nmemb, std::string* userp) {
        userp->append((char*)contents, size * nmemb);
        return size * nmemb;
    }

    int main() {
        CURL* curl = curl_easy_init();
        if(curl) {
            std::string readBuffer;
            curl_easy_setopt(curl, CURLOPT_URL, "https://api.lunastore.app/method/marketplace/search?query=123");
            curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, WriteCallback);
            curl_easy_setopt(curl, CURLOPT_WRITEDATA, &readBuffer);

            CURLcode res = curl_easy_perform(curl);
            if(res == CURLE_OK) {
                std::cout << readBuffer << std::endl;
            } else {
                std::cerr << "cURL error: " << curl_easy_strerror(res) << std::endl;
            }
            curl_easy_cleanup(curl);
        }
        return 0;
    }
    ```
  </TabItem>
</Tabs>
