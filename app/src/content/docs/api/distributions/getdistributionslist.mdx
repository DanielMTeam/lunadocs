# <Badge text="GET" variant="note" size="medium" /> `/method/distribution/getDistributionsList/`

<Aside type="caution" title="Устаревший метод (V1)">
Пути `/method/v2/distribution/getDistributionsList/` **не существует** (404). Для V2 используйте [`/method/v2/distribution/by_app/`](/api/distribution/by_app/) (`app_id`) или `distribution.by_app` через [`execute`](/api/execute/).
</Aside>

Метод позволяет получить список версий (т.е. дистрибуций), загруженных для определенной программы. Ответ - enumerated-map (`{"1": {...}, "2": {...}}`), не пагинация V2.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | ID приложения (не `app_id` - с ним будет `400`) |
