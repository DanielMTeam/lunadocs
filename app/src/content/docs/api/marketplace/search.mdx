# <Badge text="GET" variant="note" size="medium" /> `/method/v2/marketplace/search/`

Актуальный поиск приложений на базе Meilisearch. В отличие от V1, ответ приходит в привычном пагинированном формате, плюс можно фильтровать по категории, автору и бесплатности.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `query` | `string` | **Да** | Текстовый запрос ^_^ |
| `category` | `integer` | Нет | ID категории для фильтрации |
| `author` | `integer` | Нет | ID пользователя-автора |
| `is_free` | `string` | Нет | Только бесплатные приложения (`on`, `1` или `true`) |
| `limit` | `integer` | Нет | Размер страницы (по умолчанию `20`, максимум `100`) |
| `offset` | `integer` | Нет | Сдвиг выдачи (пагинация V2) |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/marketplace/search/?query=luna&limit=1' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    params = {
        'query': 'luna',
        'limit': 1,
        # 'category': 1,
        # 'author': 42,
        # 'is_free': 'true',
    }

    response = requests.get('https://api.lunastore.app/method/v2/marketplace/search/', params=params)
    print(response.json())
    ```
  </TabItem>
</Tabs>

<Aside type="caution" title="Ошибки поиска">
Если не передать `query`, API вернёт HTTP `400` с телом вида `{"error": "..."}`. Если Meilisearch недоступен - HTTP `503` с тем же форматом.
