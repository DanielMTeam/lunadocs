# <Badge text="GET" variant="note" size="medium" /> `/method/v2/marketplace/`

Каталог / лента приложений с пагинацией V2. Для поиска по тексту лучше [`/method/v2/marketplace/search/`](/api/marketplace/search/).

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `limit` | `integer` | Нет | Лимит выдачи (пагинация V2) |
| `offset` | `integer` | Нет | Сдвиг выдачи (пагинация V2) |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/marketplace/?limit=1' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get(
        'https://api.lunastore.app/method/v2/marketplace/',
        params={'limit': 1},
    )
    print(response.json())
    ```
  </TabItem>
</Tabs>
