# <Badge text="GET" variant="note" size="medium" /> `/method/v2/marketplace/{id}/`

Актуальная замена V1 `getAppInfo`: карточка одного приложения. Версии/сборки берите через [`distribution/by_app`](/api/distribution/by_app/).

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Path)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | ID приложения |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/marketplace/403/' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get('https://api.lunastore.app/method/v2/marketplace/403/')
    print(response.json())
    ```
  </TabItem>
</Tabs>
