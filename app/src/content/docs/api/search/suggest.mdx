# <Badge text="GET" variant="note" size="medium" /> `/method/v2/search/suggest/`

Лёгкий typeahead для живой строки поиска: возвращает укороченные карточки приложений и пользователей. Если в `query` меньше двух символов - просто пустые массивы, без драмы.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `query` | `string` | **Да** | Текст из строки поиска |
| `limit` | `integer` | Нет | Максимум результатов (по умолчанию `8`, максимум `20`) |
| `type` | `string` | Нет | Что искать: `all` (по умолчанию), `apps` или `users` |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/search/suggest/?query=lu&limit=2' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    params = {
        'query': 'lu',
        'limit': 2,
        # 'type': 'apps',
    }

    response = requests.get('https://api.lunastore.app/method/v2/search/suggest/', params=params)
    print(response.json())
    ```
  </TabItem>
</Tabs>
