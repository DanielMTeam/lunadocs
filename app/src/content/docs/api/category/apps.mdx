# <Badge text="GET" variant="note" size="medium" /> `/method/v2/category/{id}/apps/`

Приложения внутри категории. Актуальная замена V1 `getAppList`.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса

| Параметр | Тип | Обязательно | Где | Описание |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | Path | ID категории |
| `limit` | `integer` | Нет | Query | Лимит выдачи (пагинация V2) |
| `offset` | `integer` | Нет | Query | Сдвиг выдачи (пагинация V2) |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/category/1/apps/?limit=1' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get(
        'https://api.lunastore.app/method/v2/category/1/apps/',
        params={'limit': 1},
    )
    print(response.json())
    ```
  </TabItem>
</Tabs>
