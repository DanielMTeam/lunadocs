# <Badge text="GET" variant="note" size="medium" /> `/method/v2/category/{id}/`

Заголовок раздела: название и описание категории. Приложения внутри - через [`apps`](/api/category/apps/).

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Path)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | ID категории |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/category/1/' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get('https://api.lunastore.app/method/v2/category/1/')
    print(response.json())
    ```
  </TabItem>
</Tabs>
