# <Badge text="GET" variant="note" size="medium" /> `/method/v2/collection/by_user/`

Список публичных коллекций, которыми владеет указанный пользователь. Удобно для вкладки "Коллекции" на профиле.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `user_id` | `integer` | **Да** | ID владельца коллекций |
| `limit` | `integer` | Нет | Лимит выдачи (пагинация V2) |
| `offset` | `integer` | Нет | Сдвиг выдачи (пагинация V2) |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/collection/by_user/?user_id=1' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get(
        'https://api.lunastore.app/method/v2/collection/by_user/',
        params={'user_id': 1},
    )
    print(response.json())
    ```
  </TabItem>
</Tabs>
