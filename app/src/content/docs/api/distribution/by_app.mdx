# <Badge text="GET" variant="note" size="medium" /> `/method/v2/distribution/by_app/`

Версии / сборки приложения для вкладки "Скачать". Актуальная замена V1 `getDistributionsList`.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Query)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `app_id` | `integer` | **Да** | ID приложения |
| `limit` | `integer` | Нет | Лимит выдачи (пагинация V2) |
| `offset` | `integer` | Нет | Сдвиг выдачи (пагинация V2) |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">

    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/distribution/by_app/?app_id=403' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get(
        'https://api.lunastore.app/method/v2/distribution/by_app/',
        params={'app_id': 403},
    )
    print(response.json())
    ```
  </TabItem>
</Tabs>

### <Icon name="comment-alt" color="var(--sl-color-accent)" /> Формат ответа

Пагинированный список дистрибутивов:

```json
{
  "count": 1,
  "next": null,
  "previous": null,
  "results": [
    {
      "id": 4760,
      "app": 403,
      "version": "1.0",
      "link": "/get_dist_file/4760/",
      "url": "",
      "has_download": true,
      "published": "2026-08-03T17:48:54.908257Z",
      "release_description": null
    }
  ]
}
```

<Aside type="note" title="Скачивание">
Если `has_download: true`, файл лежит по относительному пути `link`. Поле `url` - внешняя ссылка (если сборка не на CDN).
</Aside>
