# <Badge text="GET" variant="note" size="medium" /> `/method/v2/distribution/{id}/`

Карточка одной сборки: версия, ссылка на файл, дата публикации и описание релиза.

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Path)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | ID дистрибутива |

---

### <Icon name="rocket" color="var(--sl-color-accent)" /> Пример использования

<Tabs>
  <TabItem label="cURL" icon="terminal">
    ```bash
    curl -X 'GET' \
      'https://api.lunastore.app/method/v2/distribution/4760/' \
      -H 'accept: application/json'
    ```
  </TabItem>
  <TabItem label="Python" icon="seti:python">
    ```python
    import requests

    response = requests.get('https://api.lunastore.app/method/v2/distribution/4760/')
    print(response.json())
    ```
  </TabItem>
</Tabs>
