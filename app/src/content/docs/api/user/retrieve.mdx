# <Badge text="GET" variant="note" size="medium" /> `/method/v2/user/{id}/`

Публичный профиль пользователя. Поиск по нику - [`/method/v2/user/search/`](/api/user/search/), коллекции - [`by_user`](/api/collection/by_user/).

---

### <Icon name="open-book" color="var(--sl-color-accent)" /> Параметры запроса (Path)

| Параметр | Тип | Обязательно | Описание |
| :--- | :--- | :--- | :--- |
| `id` | `integer` | **Да** | ID пользователя |

---
