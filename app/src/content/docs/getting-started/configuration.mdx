В основе настройки LunaStore лежит файл `.env` в корне репозитория. Шаблон - [`.env.example`](https://github.com/DanielMTeam/lunastore/blob/main/.env.example). Скопируйте его в `.env` и правьте под свой инстанс.

<Aside type="note" title="django-constance">
  Многие настройки ниже управляются через django-constance: правки из админки могут синхронизироваться обратно в `.env`. Ручные правки файла обычно требуют перезапуска приложения.
</Aside>

## <Icon name="setting" color="var(--sl-color-accent)" /> Основные настройки инстанса и Django

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `VERSION` | Версия инстанса LunaStore | `"2.7"` |
| `ADMIN_URL` | Путь до панели администратора | `".."` |
| `EXTERNAL_MEDIA_URL` | URL раздачи UGC / медиа | `"http://192.168.1.10/media/"` |
| `SECRET_KEY` | Секретный ключ Django | `""` |
| `DEBUG` | Режим отладки (`"True"` для dev, `"False"` для prod) | `"True"` |
| `ADMIN_EMAIL` | Контактный E-mail администратора | `"questions@example.com"` |

<Aside type="danger" title="Обратите внимание!">
* **`SECRET_KEY`**: должен быть максимально сложным. Ни при каких обстоятельствах не светите его публично.
* **`DEBUG`**: `"True"` только для разработки. В production строго `"False"`, иначе рискуете утечкой данных и параметров сервера.
</Aside>

## <Icon name="document" color="var(--sl-color-accent)" /> База данных (PostgreSQL)

| Переменная | Описание | Пример / По умолчанию |

## <Icon name="external" color="var(--sl-color-accent)" /> Авторизация (OpenID / Authentik)

Если используете сторонний OIDC-провайдер (например, Authentik):

| Переменная | Описание |
| :--- | :--- |
| `OIDC_CLIENT_ID` | Client ID |
| `OIDC_CLIENT_SECRET` | Client Secret |
| `OIDC_ENDPOINT` | Базовый endpoint провайдера |
| `OIDC_TOKEN_ENDPOINT` | Endpoint выдачи токенов |
| `OIDC_USER_ENDPOINT` | Endpoint профиля пользователя |
| `LOGIN_REDIRECT_URL` | Куда редиректить после входа |
| `LOGOUT_REDIRECT_URL` | Куда редиректить после выхода |
| `OIDC_SIGN_ALGO` | Алгоритм подписи (например, `RS256`) |
| `OIDC_JWKS_ENDPOINT` | JWKS для проверки подписей |

## <Icon name="approve-check" color="var(--sl-color-accent)" /> Поиск (Meilisearch)

Полнотекстовый поиск приложений и пользователей.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `MEILISEARCH_ENABLED` | Включён ли Meilisearch | `"True"` |
| `MEILISEARCH_URL` | URL инстанса (внутри Docker обычно `http://meilisearch:7700`) | `"http://meilisearch:7700"` |
| `MEILI_MASTER_KEY` | Master key Meilisearch (в prod обязательно смените) | `"change-me-in-production"` |

<Aside type="tip">
  После первого наполнения каталога прогоните `reindex_search` (в dev: `make dev-reindex-search`), иначе поиск может быть пустым.
</Aside>

## <Icon name="forward-slash" color="var(--sl-color-accent)" /> Сеть, домены и безопасность

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `ALLOWED_HOSTS` | Разрешённые хосты. Разделитель - `;` | `"192.168.1.10;127.0.0.1"` |
| `TRUSTED_PROXIES` | Прокси, которым можно доверять `CF-Connecting-IP` / `X-Real-IP` / `X-Forwarded-For` | `"10.0.0.0/8;127.0.0.1"` |
| `CORS_ALLOWED_ORIGINS` | Origins для CORS | `"http://192.168.1.10"` |
| `CSRF_TRUSTED_ORIGINS` | Доверенные origins для CSRF | `"https://lunastore.app"` |
| `SESSION_COOKIE_DOMAIN` | Домен session cookie | `".lunastore.app"` |
| `CSRF_COOKIE_DOMAIN` | Домен CSRF cookie | `".lunastore.app"` |
| `MOTD_LIST` | Сообщения дня (MOTD), через `;` | `"Windows XP;время подавать напитки"` |
| `GEO_DOMAIN_PROXY_ENABLED` | Гео-проксирование на региональные домены | `"True"` |
| `GEO_DOMAIN_OVERRIDES` | JSON с override доменов по стране (`BASE_URL` / `API_URL` / `SPIRE_URL`) | см. `.env.example` |
| `ALLOW_MODERATOR_LOGIN_AS_USER` | Разрешить модератору логиниться как пользователь | `False` |
| `ENABLE_DRM` | Включить DRM-логику | `"True"` |
| `ENABLE_DISTRIBUTION_PROXY` | Проксирование скачивания дистрибутивов | `"True"` |

## <Icon name="puzzle" color="var(--sl-color-accent)" /> ClickHouse analytics (опционально)

По умолчанию выключено. Поднимается профилем Compose `analytics`.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `ANALYTICS_ENABLED` | Включить аналитику | `"False"` |
| `CLICKHOUSE_HOST` | Хост | `"clickhouse"` |
| `CLICKHOUSE_PORT` | HTTP-порт | `8123` |
| `CLICKHOUSE_USER` | Пользователь | `"analytics"` |
| `CLICKHOUSE_PASSWORD` | Пароль | `"analytics"` |
| `CLICKHOUSE_DATABASE` | База | `"lunastore_analytics"` |
| `CLICKHOUSE_SECURE` | HTTPS к ClickHouse | `"False"` |

<Aside type="tip">
  Dev: `make dev-analytics-up`, затем `make dev-analytics-migrate`. Prod: `make analytics-up` / `make analytics-migrate`.
</Aside>
