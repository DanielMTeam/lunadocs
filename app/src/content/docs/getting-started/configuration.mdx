В начале было слово, а в основе настройки LunaStore лежит конфигурационный файл переменных окружения. Он имеет название `.env`. Вы можете использовать `env.example` из корня репозитория как шаблон. Ниже приведено описание всех параметров.

## <Icon name="setting" color="var(--sl-color-accent)" /> Основные настройки инстанса и Django

Базовые параметры и общие настройки фреймворка.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `VERSION` | Версия инстанса LunaStore | `"2.0"` |
| `ADMIN_URL` | Путь до панели администратора | `"admin"` |
| `EXTERNAL_MEDIA_URL` | Прямая ссылка для раздачи UGC | `"/media/"` |
| `SECRET_KEY` | Секретный ключ Django | `""` |
| `DEBUG` | Режим отладки | `"True"` |
| `ADMIN_EMAIL` | Контактный E-mail администратора проекта | `"questions@myslivets.com"` |

<Aside type="danger" title="Обратите внимание!">
* **`SECRET_KEY`**: Крайне важно, чтобы данный ключ был сложным настолько, насколько это возможно. Чорт побери, ни при каких обстоятельствах не стоит кому-либо говорить данный ключ.
* **`DEBUG`**: Включайте (`True`) **только** для разработки/отладки. По окончанию технических работ, этот параметр СТРОГО должен быть `"False"`, иначе Вы рискуете слегка глупой утечкой данных и параметров вашего сервера на публичное обозрение.
</Aside>

## <Icon name="document" color="var(--sl-color-accent)" /> База данных (PostgreSQL)

Параметры для подключения к вашей СУБД.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `DB_NAME` | Название базы данных | `""` |
| `DB_USER` | Имя пользователя базы данных | `"db"` |
| `DB_PASSWORD` | Пароль пользователя БД | `""` |
| `DB_HOST` | Хост базы данных. Если PostgreSQL крутится в том же Docker-окружении, обычно указывают `db` | `"db"` |
| `DB_PORT` | Порт для подключения к базе данных | `""` |

## <Icon name="external" color="var(--sl-color-accent)" /> Авторизация (OpenID / Authentik)

Если Вы используете сторонний провайдер аутентификации (например, Authentik), приведите в порядок эти параметры.

| Переменная | Описание |
| :--- | :--- |
| `OIDC_CLIENT_ID` | Идентификатор клиента OpenID (Client ID) |
| `OIDC_CLIENT_SECRET` | Секретный ключ клиента (Client Secret) |
| `OIDC_ENDPOINT` | Основной URL (эндпоинт) вашего OpenID-провайдера |
| `OIDC_TOKEN_ENDPOINT` | Эндпоинт для получения токенов доступа |
| `OIDC_USER_ENDPOINT` | Эндпоинт для запроса данных профиля пользователя |
| `LOGIN_REDIRECT_URL` | Куда перенаправлять пользователя после успешного входа |
| `LOGOUT_REDIRECT_URL` | Куда перенаправлять пользователя после выхода (логаута) |
| `OIDC_SIGN_ALGO` | Алгоритм подписи токенов (например, `RS256`) |
| `OIDC_JWKS_ENDPOINT` | Ссылка на JSON Web Key Set (JWKS) для проверки подписей |

## <Icon name="random" color="var(--sl-color-accent)" /> Интеграция с LunaSpire и API

Настройки связи между компонентами платформы.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `LUNASPIRE_SECRET_KEY` | Секретный ключ от движка LunaSpire (должен совпадать с настройками самого LunaSpire). | `"supersecretkey"` |
| `LUNASPIRE_URL` | Полный URL до инстанса LunaSpire | `"http://192.168.1.10:8080"` |
| `LUNASPIRE_URL_WITHOUT_PROTO`| Домен инстанса LunaSpire (без `http/https`) | `"spire.lunastore.app"` |
| `API_URL` | Внутренний или внешний URL для обращений к API LunaStore | `"http://192.168.1.10:7088"` |

## <Icon name="forward-slash" color="var(--sl-color-accent)" /> Сеть, домены и безопасность

Настройки CORS, куки и ограничений по хостам.

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `ALLOWED_HOSTS` | Список разрешенных IP/доменов, с которых доступен сайт. Разделитель — `;` | `"192.168.1.10;192.168.1.1"` |
| `CORS_ALLOWED_ORIGINS` | Домены, которым разрешено делать кросс-доменные запросы (CORS) | `"http://192.168.1.10;..."` |
| `CSRF_TRUSTED_ORIGINS` | Доверенные источники для проверки CSRF токенов | `"https://lunastore.app"` |
| `SESSION_COOKIE_DOMAIN` | Домен для установки сессионных куки (начинается с точки) | `".lunastore.app"` |
| `CSRF_COOKIE_DOMAIN` | Домен для установки CSRF куки | `".lunastore.app"` |
| `MOTD_LIST` | Слоганы. Основываются на компоненте "Сообщения дня (MOTD)". Разделяются через `;` | `"Windows XP;время подавать напитки и вершить судьбами"` |

## <Icon name="laptop" color="var(--sl-color-accent)" /> Регистрация, аккаунты и инвайты

Управление системой аккаунтов

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `BCRYPT_ROUNDS` | Количество раундов хеширования паролей (влияет на безопасность и нагрузку, чем больше число тем сложнее, но мы рекомендуем оставлять значение по умолчанию) | `12` |
| `REGISTRATION_IS_ENABLED` | Включена ли открытая регистрация (`True`/`False`) | `"True"` |
| `DEVELOPER_REGISTRATION_IS_ENABLED`| Разрешено ли пользователям подавать заявки на статус разработчика | `"True"` |
| `INVITES_ON_REGISTER` | Регистрация только по инвайт-кодам (`True`/`False`) | `"True"` |
| `MAX_INVITE_USES_COUNT` | Сколько раз можно использовать один инвайт-код | `3` |
| `MAX_INVITE_DAYS_LIMIT` | Дневной лимит на количество выданных приглашений | `7` |
| `RETENTION_ACTIVITY_LOG_DAYS`| Срок хранения логов активности пользователей (включая IP) в днях для соблюдения GDPR | `0` |

## <Icon name="rocket" color="var(--sl-color-accent)" /> Рейтлимиты и логгирование

Защита от DDoS/брутфорса и мониторинг изменений в инстансе

| Переменная | Описание | Пример / По умолчанию |
| :--- | :--- | :--- |
| `RATE_LIMIT_ENABLED` | Включены ли рейтлимиты (`True`/`False`) | `"True"` |
| `RATE_LIMIT_WINDOW` | Количество запросов, разрешенных за указанный промежуток времени | `25` |
| `RATE_LIMIT` | Время в секундах, за которое считаются запросы (окно) | `45` |
| `TELEGRAM_LOGGER_ENABLED` | Включена ли отправка логов ошибок/событий в Telegram | `True` |
| `TELEGRAM_BOT_TOKEN` | Токен вашего бота Telegram (от BotFather) | `""` |
| `TELEGRAM_LOG_CHAT_ID` | ID чата/группы, куда бот будет присылать логи | `""` |
| `TELEGRAM_LOG_TOPIC_ID` | ID конкретного топика (ветки), если логи отправляются в группу с темами | `""` |
